## U27：core 接线（判定与结构）✅ 已提交

- **选题**：缺口 ⑪ 的第一批（USABILITY §8「剩余」行、TASKS.md 缺口 ②–⑥⑧）—— core 里**全是现成原语**，
  缺的只是接线。选它而不是 Cayley/画布打磨：⑪ 是明写的"下一步"，且每条都有【手算对照表】可写断言。
- **六条新操作**（注册表 32 → 38）：`gcd` / `lcm` / `phi`（`\varphi(n)`，走 `factorizeOrder`）·
  `轨道数(A)`（**Burnside**：本系统直接数轨道 + core 定理实现的平均，副行对账 `40 / 8 = 5 v`）·
  `极大子群(G)`（**子群格指向 G 的覆盖边**）· `Inn(G)`（≅ `G/Z(G)`，商掉中心）。
- **「结构」节**（`gal/structure.ts`，纯函数 + 缓存）进 InfoDock 「基本」tab：完美 · 合成列（因子+条数）·
  导来列（阶链）· 分解（**直积优先**：`D₆ ≅ D₃ × C₂` 优先于 `C₆ ⋊ C₂`；没分解就点名"单群"）。

  ② `极大子群` 超 `ENUMERATION_LIMIT` **自己拦** —— core 的 `computeSubgroupLattice` 超限时
  **静默退化成 {e} 与 G 两点**（实测 216 阶），照单全收会把**平凡子群**当极大子群。

  `no-unicode-leak.mjs` 的报错面样本同样换掉。
