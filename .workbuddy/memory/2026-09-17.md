## U6 第二阶段：布局网格化（用户："我只想快点看到交换图……继续做吧"）

- **动机**：用户要的"交换图"是**视觉**问题——DIAGRAM_SPEC §1.2 说的第一判据"水平箭头同高、垂直箭头同列"没做到，图就不像课本。所以跳过功能（作用线/共轭作用），先做 **U6-A 布局网格化**。
- **改法**（`ui/CanvasView.tsx` 的 `view` useMemo）：把"推挤"换成**硬约束网格**
  1. **行 = 派生层**（level）：同层 y **严格相等**，行高 = 该行最高节点，行间距 `ROW_GAP = 76`
  2. **列 = 竖直约束的连通分量**（并查集）：
     - 只有 **结构伴生边**（`π` / `π₁` / `π₂` / `↪`）要求两端同列
     - 用户造的映射（带 `objectId`）是**水平**的、`≅` 是**对角**的、来源线是辅助 → 都**不**参与
     - 一行内撞列时右移到最近空列（`firstFree`），**组按初值 x 排序**决定左右顺序
  3. **列宽 = 该列最宽节点**，列间距 `COL_GAP = 64`
  - `computeLatticeLayout` 降级为"只出初值"（定行列的相对次序），最终坐标由网格重算
  - 常量 `GAP_X`（推挤时代）→ `COL_GAP` / `ROW_GAP`
- **踩坑（关键）**：第一版判据按**几何**猜（"`dy ≥ dx` 的边要求同列"）→ `≅` 这条对角边把
  `C₆`、`C₃`、`C₆/ker φ` **传染成一列**（`C₆` 与 `C₃` 直接叠在一起、完全重合）。
  改成**按边的语义**判（只有 π/π₁/π₂/↪ 约束同列）后立刻正确。
  → 教训：**布局约束要从"这条边在数学上是什么"来，不能从"它现在画成什么样"来反推。**
- **效果**：第一同构定理自动排成课本形 —— `C₆ ──φ──▶ C₃` 水平（同 y）、
  `C₆ ──π──▶ C₆/ker φ` 垂直（同 x）、`≅` 对角。左边 `D₄` 组（Z(G)/[G,G] 一行、Z∩C/D₄/N 一行）同样规整。
  截图 `docs/assets/u6-grid.png`。
- **验证**：新增走查 `shot-grid.mjs`——**用节点坐标做断言**（同列 x 严格相等 / 同行 y 严格相等 /
  不同列 / 有落差），比"看起来对"硬。ALL PASS · U0–U6 断言 264 项全绿 · 7 套走查 ALL PASS · 控制台零错误。
- 文档：INTERACTION §8.1 重写为网格口径 · DIAGRAM_SPEC §2.1 标"已修复"+§4 表格 A 打勾 ·
  ROADMAP U6 进度 · README（状态 + 截图）。

## 定理复现体检（用户："去网上搜常见群论定理的交换图，看本项目能不能复现；复现不出来就说明有地方没做好"）

- **四条完整复现**：第一同构（三角形/正方形）· **第二同构**（菱形）· 轨道-稳定子的计算部分。
- **两条卡缺口**：第三同构（`(G/N)/(K/N)`）、Sylow III（`G ↷ Syl_p(G)`）。

### 体检修掉的三个缺口

- **G1 元素记号不认数学惯例**：`闭包(G, r4)` 报"没有元素 r4"。根因：**core 的 `C_n` 是加法群**
  （生成元名 `a`、元素 `0..n-1`），而课本写乘法循环群 `r^k`。
  → 新增 `resolveElementLoose`（ops.ts）三级回退：① core 精确（含循环记号 `(123)`）
  ② **生成元的幂** `r4`/`r^4`/`r^{4}` ③ **单生成元群的单字母别名**（`r`/`a`/`g` 互通）。
  同时 `generatorOf`（映射构建时的生成元记号）也加了同样宽容。
- **G3 子群之交不升级**：`H∩N` 是 `elements` ⇒ 画布上是个"集合圆"，**没有 `↪` 包含箭头**（只有虚线来源线）。
  → `setOp` 在 `∩`/`·` 且结果**确实是子群**时升级为真群对象（`isSubgroupElementSet` 判定），
  `derive` 把 `intersection`/`productSet` 加进 `SUBGROUP_RESULT_OPS`。
  **与决策 ⑤ 的界线**：⑤ 的"不自动升级"针对**用户手工造集合**（是不是子群要判断）；
  两个子群之交必是子群 —— **这是定理，无需判断**。
- **G3b `闭包(J)` 得到平凡群**（**U0 就埋着的老 bug，只有体检才挖出来**）：
  `closure` 的 `if (G0)` 把"单个群参数"也当成"母群 + 空生成元表"⇒ 返回平凡群。
  既有断言全绿因为**只测了 `闭包(G, r2)` 形态**。→ 改成 `if (G0 && a.length > 1)`。
