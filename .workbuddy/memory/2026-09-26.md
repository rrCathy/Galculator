## 做了什么（U20 = 子群像 + 声明包含）

### ① 子群像 `像(f, H)`
**扩 `image` op 的可选第二参**，不新开 op —— 用户嘴里都叫"像"，`像` 这个别名只该指向一条路。
- `params: [{f, map}, {H, group, optional: true}]`，`arity: 1, optional: 1`
- 三关：`|H| ≤ |定义域|` → H 的 id 全覆盖 → `subgroupFromElementIds` 认可
- 逐元素取像；映射表缺词条 → 报"映射不完整"，**不静默**
- 实测：S₄↠S₃（`映射(G, S_3, s12→23, c→13)`，ker = V₄）下 `像(f, A_4)` = **3 阶 C₃**
  （A₄/V₄ ≅ C₃ ✓）；单参 `像(f)` 仍给整个像（6 阶）
- **叙述分家**：`f(A)` 的面板说 `FA = f(A)`，不是 `= im f`。这条是看截图才发现的——
  `relations.ts` 原来一律写 `= im f`，扩展到两参后名称就对不上了

### ② 声明包含 `H ⊆ G`（新值类型 `relation`）
- `value.ts`：`GalRelation{from,to,index,isNormal,normalUnknown}`；`sortOf → 'edge'`；
  `canvasShape → 'edge'`；`contextGroup → 母群 to`
- `ops.ts`：`contains` op（`call: ['包含','include','subset']`、`infix: ['⊆']`），
  **判定复用 U19 的 `containment()`**（判据同源：声明的与算出来的不许有两种说法）
- `types.ts`：`GalEdge.kind += 'relation'`
- `derive.ts`：关系对象 → 一条 `gedge-relation` 边，`label = isNormal ? '⊴' : '↪'`，
  `arrow: 'injective'`，带 `objectId`（可点选）；**先让声明的压过自动生成的同向 `↪`**（不叠两条）
- `CanvasView.tsx`：关系边算竖直约束（跨层时）、也算水平相邻对（同层时）、渲染与显式映射同档
- **正规性是算出来的，不是声明的** → 没有"声明正规子群"这个操作，也无从撒谎
- **指数 1 拒收**（元素完全相同 = 同一个群，包含是严格小于）
- 三种写法等价：`R = A ⊆ G` · `R = A⊆G` · `R = 包含(A, G)`
- 假声明全在**输入层**拦住并给理由（阶反了 / 不是子集 / 乘法不封闭 / 同一个群 / 名字打错）
- `evalDef.ts`：`⊆` 进 `UNICODE_ALIASES`（不补空格也认）；并且趁 `⊆` 的"独占性"
  做了一件直积的 `x` 不能做的事 —— `R = A ⊆ K9`（某侧打错）**直接报"是哪一侧算不出来"**

### ③ 顺带修掉一个**布局老 bug**（不是新功能引入的）
两条**水平边共用一个端点**时，老的"把夹在中间的组挪到行尾"会**自相打架**：
满足 `A→G` 要把中间的 H 挪走，满足 `G→H` 又要把中间的 A 挪走，震荡回原样。
- 实测（U20 之前的形状）：`phi: G→H` + `psi: B→G` → `psi` 的线从 `H` 身上**横穿**（违反 §1.2）
- **老走查只判了竖直穿行，水平那半没判** → 所以一直没被发现
- 新法：水平边当约束图 → **分量内穷举列序，取"被夹住的边最少"者**；
  **并列只接受严格更优**（布局要稳）；分量 > 7 保持原序不猜
- 修后：`H·G·B` 排成一条链；`H(S₃) | G | A₄` 也成链，两条边都不再穿行

## 本轮踩到的坑（已补进 verify/README 的 21–24 条）
1. **走查里点画布上的边/节点不能用 `page.click`**：`.gedge-hit` / `.gnode-hit` 的
   `stroke`/`fill` 是 `transparent`，Playwright 判它 "not visible" → 白等 30s 后 TimeoutError。
   改派发事件（`el.dispatchEvent(new MouseEvent('click', {bubbles:true}))`，React 18 监听在根容器）。
2. **断言里不要 `JSON.stringify(值)`**：`Group.generators[].inverse` 指回生成元自己（环）→
   抛 `Converting circular structure to JSON`，**整份回归崩在那一行**（不是只失败一条）。
   写 `describeValue()` 只摘 symbol/order/index/isNormal。
3. **老走查的几何判据只有"竖直不穿行"**——水平那半补上之后立刻抓出了上面那个老 bug。
   教训：判据要成对；只判一半会让人以为"没报错就是对的"。
4. **`⊆` 不补空格会被 `findTopLevelInfix` 当成整词**：`∩`/`∪`/`·` 的解法一样，进 `UNICODE_ALIASES`。
