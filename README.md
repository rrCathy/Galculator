# Galculator

群论计算器：把**计算**和**证明**放在同一张可操作的交换图上。

你敲一行群论定义，画布上长出对象；你点一个对象做运算，运算本身就变成图上的箭头。
Desmos 把函数变成曲线，这里把群论计算变成交换图。

![默认示范：Sylow III 的完整故事](docs/assets/u11-default-sylow.png)

## 为什么做

- 群论抽象、门槛高。Sylow 定理人人会背，但很少有人真正**看见**论证怎么展开。
- Desmos / GeoGebra 覆盖了实函数与几何，**群论没有对应的计算器**。

## 定位

| 参照 | 借什么 |
|---|---|
| Desmos / GeoGebra | 交互的即时反馈。**但画布的角色相反**：它们是输出，这里的画布是操作台 |
| Group Explorer | 群论可视化的约定（凯莱图 / 群作用 / 乘法表） |
| Lean / Coq | **不碰**。形式化证明是另一件事；这里做的是演示性证明 —— 模板人工写，机器在具体群上实例化并画出来 |

目标场景：**用群作用证明 Sylow 定理**，一步步走完，画布跟着长出证明图。

## 快速开始

```bash
pnpm install
pnpm dev          # → http://127.0.0.1:5273
```

打开就有一张默认示范（Sylow III 的完整故事）。想从空白开始：`http://127.0.0.1:5273/?empty=1`。

**三步上手**：在画面正下方的 `✎` 输入球里敲

```
G = S_4
```

回车，画布上出现 `S_4`。再敲 `A = A_4`。然后从 `A` 拖到 `G` 松手 —— 工具自己判断这两个群之间能做什么。

## 能写什么

输入框是「名字 + 表达式」两块：名字留空会**自动命名**，表达式**边打边校验**（合法就当场说会产出什么，非法给红字与定向提示）。
文本一律 **ASCII**（`S_4` 而不是 `S₄`，`\varphi` 而不是 `φ`）—— 敲不出来的字符会被拦下并给出可照抄的改法；显示侧走 KaTeX 真排版。

| 输入 | 机制 | 产物 |
|---|---|---|
| `G = S_4` · `G = D_4` · `G = C_2 x C_2` | 记号建群 | 群节点 |
| `P = G x H` · `Q = G / Z` | 原子构造（直积 / 商群） | 群节点 + π / π₁π₂ 伴生箭头 |
| `A = 共轭作用(G)` · `A = 共轭作用在(G, Ω)` · `A = 陪集作用(G, H)` | 原子构造（作用） | 作用对象 + 作用线（可点选，直接铺出轨道 / 稳定子） |
| `Z = Z(G)` · `Cg = [G,G]` · `N_G(G, H)` · `C_G(G, x)` · `Inn(G)` | 作用导出（子群） | 群节点（子群是**真群对象**，所以 `Z(Z(G))` 合法） |
| `I = A \cap B` · `∪` · `\setminus` · `\cdot` | 集合运算 | 集合节点（∩ 与 · 若结果是子群，升级为群对象） |
| `R = A \subseteq B` · `R = A \cong B` | 声明关系 | 画布上一条可点选的 `⊴` / `↪` / `≅` 边（正规性由工具判，不由你声明） |
| `K = <J>` · `闭包(G, r2)` | 迭代（闭包） | 群节点 |
| `f = 映射(G, H, r→0, s→0)` | 原子构造（同态） | 实线箭头（不占节点，**可点选** → 环绕出 `ker` / `im`） |
| `O = 轨道(A, r)` · `稳定子(A, r)` · `Fix(A)` · `轨道数(A)` | 作用导出 / Burnside | 集合节点 / 数值（Burnside 平均式当场对账） |
| `S = Sub(G)` · `pSub(G, 2)` · `Syl(G, 2)` · `极大子群(G)` | 枚举 + 筛 | 子群集（每一项都能「取出为对象」） |
| `ord(G, (123))` · `C(12, 4)` · `Cmod(12, 4, 2)` · `gcd` · `lcm` · `phi(12)` | 属性 / 算术 | 数值（左下数值区） |

元素参数走 core 的 `resolveElement`：`id` / `label` / 循环记号都命中，所以 `ord(S_4, (123))` 合法。
全部 39 条操作在 [`apps/web/src/gal/ops.ts`](apps/web/src/gal/ops.ts) 的注册表里（每条声明机制、命名参数与类型，菜单由 `opsFor(selection)` 派生）。

## 界面上有什么

- **正下方 `✎` 输入球**：唯一的文本入口；点出来的操作也会被编回一行文本走同一个求值器，所以「点出来的」和「打出来的」行为必然一致。
- **左上三个抽屉**：`对象`（手写的定义）与 `操作`（运算产物）同列上下，`信息` 另一列 —— 信息面板只回答"这个对象是什么"：**结论**（识别 / 同构 / 第一同构定理）＋ `基本` / `元素` / `子群` **三个可折叠分区**（单开、默认全收，标题行带一行摘要：阶 / 元素个数 / 子群同构类数）。结论那句"答案"是面板里最大的一档（20px），其余按对象名 / 分区标题 / 附注依次收小 —— 一眼先看到结果。
- **点画布上的节点** → 冒出一颗悬浮球，环绕「基本 / 元素 / 子群 / 操作」；前三个是「看」（打开面板并展开对应分区）。
- **拖拽连线**：从 A 拖到 B 松手，列出这两个对象能做的事；唯一候选直接执行。
- **右上证明面板**：5 条定理模板（Sylow I / II / III · 轨道-稳定子 · 第一同构），逐步演示 —— 「下一步」把这一步的定义真的写进定义表，画布跟着长。
- **右下工具条**：缩放 / 适应窗口 / 恢复自动布局 / 视图快照（把整张图存成一段文本带走）/ 清空画布。画布自动保存，刷新还在。

## 画布上的规则

三条硬规范，不是「尽量对齐」：

- **形状 = 类型**：群是一块淡底上的符号，集合是圆。
- **颜色 = 来源**：蓝 = 手写输入，紫 = 运算产物，绿 = 作用。
- **箭头形状 = 映射类型**：`↠` 满射双箭头，`↪` 单射尾钩，`≅` 两端尖。判不出就不猜，退回普通箭头。

水平箭头同高、垂直箭头同列，对象落在格点上（格点画得出来，能拖能吸附）。细则见 [docs/DIAGRAM_SPEC.md](docs/DIAGRAM_SPEC.md)。

## 项目结构

```
apps/web/                Vite + React 19 + TypeScript（pnpm monorepo）
  src/gal/               纯逻辑层，无 React，可单测
    value.ts             8 种值类型 + 存在层级（顶点 / 边 / 列表 / 标量）
    ops.ts               操作注册表：机制 / 参数类型 / 求值 / 配方
    evalDef.ts           求值（引用 → 调用 → 中缀 → 记号）
    build.ts             定义行 → 对象表
    derive.ts            对象表 → 画布图（含结论自动成边）
    relations.ts         包含判定：H ≤ G？正不正规（画布 / 拖拽 / 集合运算共用）
    embedding.ts         「G 里有没有与 H 同构的子群」—— 跨 id 空间对齐的判据源
    parents.ts           子群 → 母群的指针（core 的 Group 没有 parent 字段）
    structure.ts         完美 / 合成列 / 导来列 / 直积或半直积分解
    proof.ts             Proof Spec 执行侧 + 5 条模板
    grid.ts              格点与吸附（纯函数）
    snapshot.ts         视图快照的序列化与校验
    board.ts             画布自动保存
    pretty.ts / tex.ts   记号归一（全 ASCII）与 LaTeX 渲染
  src/ui/                画布与面板：CanvasView（SVG 交换图）/ 三个抽屉 / 输入球与悬浮球 / 证明面板 / 映射构建器
  verify/                回归线（入库，是资产不是临时物）
    suites/              语义层断言（16 组，纯逻辑）
    e2e/                 真浏览器几何走查（24 套，读 DOM 坐标与 marker）
    README.md            跑法、约定与写断言时的坑
docs/                    架构 / 交互 / 图规范 / 证明规范 / 可用性审计 / 规划
```

## 状态与边界

**已落地**：U0–U42 的界面与交互迭代、M0–M3 里程碑（含 5 条定理模板逐步演示）。逐批的取舍与验收账在 [docs/ROADMAP.md](docs/ROADMAP.md) 与 [docs/USABILITY.md](docs/USABILITY.md)，本文件不复述。

**还没有的**：Cayley 定理的模板（缺「忠实作用 ⇒ 嵌入」在图上的落点）· 集合构造器 · 宏 · 工具条与群目录 · 后端计算栈（GAP 推迟，目前全靠 `@groupviz/core` 的前端原语）。

**已知边界**（有意为之，不是待修的 bug）：

- `像(f, H)` 在 H 有多个嵌入时**不自动翻译** —— `f(H)` 是一个具体的子群，「取哪个嵌入的像」说不准。
- 大群有硬上限（子群枚举 / 结构节 `|G| ≤ 60`）。超限时**明说「没算」**，不会拿一个错答案糊过去。
- 正规性跳不过元素：`H ⊴ G` 问的是「G 里那个具体拷贝稳不稳」，裸群说不出是哪一个 —— 这时如实回「未判定」。
