1. **展示层 `prettySymbol` 不认希腊字母与 `\mathrm`**：`\alpha_{2}` 掉进末尾"去反斜杠"兜底 →
   `alpha₂`（半截货）；`\mathrm{id}` → `mathrmid`。补了 `GREEK` 表 + `\mathrm/\mathbb/\operatorname/\text` 展开。
2. **回认层缺失**：面板给你看 `α₂`，照着敲回去系统说"没有这个元素"（core 用 `resolveElement` 只认引擎记号）。
   在 `resolveElementLoose` 最前面加第 **⓪ 级**：按 `prettySymbol` 的**唯一命中**回退（多对一时拒绝，不猜）。
   于是 `α₂` / `\alpha_2` / `\alpha_{2}` 三种写法同值。
3. **6 个漏渲染的面板字段**才轮到 UI：InfoDock 的生成元 / 元素集 / 子群标签 / 集合成员 / Ω 的点 / 生成元像 /

## 二号：M2（U14 的后半）
- 新增 `SYLOW_II`（A₄/p=3，10 步）与 `SYLOW_III`（A₄/p=3，14 步）。
- **放开 `共轭作用在(G, Ω)`**：作用群可以是 Ω 母群的**子群**——这是 Sylow III 的 `P ↷ Ω` 之前的死结
  （Ω 的成员是母群 G 的子群，不是 P 的子群）。判据用 `isSubgroupElementSet`，共轭仍在母群里做。
- **顺带抓到两个可见缺陷**（都是看截图发现的，不是断言发现的）：
  1. 图上同时有两个作用时，轨道节点**同名** `Orb(1)`，且不动点无论作用叫什么都标成 `Fix(A)` →
     标签改成带作用名：`Orb_A(1)` / `Orb_B(1)` / `Stab_A(1)` / `Fix_B`。
  2. `不动点` 是**孤点**（没有任何边）：伴生边那一支只认 `orbits`，不动点落到来源线一支——
     而它的来源是**作用**（作用不是节点）⇒ 一条边都生不出来。derive 里把它并进轨道那一支。

## 本轮踩到的坑（已补进 skill `vite-logic-verification`）
- **`.orb-center` 有两颗**（输入球与多对象球共用类名）→ `.first()` 点到多对象球，输入卡片永远打不开。
