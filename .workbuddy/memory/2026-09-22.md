## 做了什么（U15）
**一句话**：三条 Sylow 模板从 `build()` 改成 `build(群, p)`，面板上多了参数控件，
于是"同一份证明骨架换任意群任意 p 都能跑"。

- `gal/proof.ts`：
  - `build(group?, p?)`，默认参数不变（A₄/p=2、A₄/p=3），所以 `SYLOW_I.build()` 语义未变。
  - `params` → **`defaults`**（面板预填）；新增 `groupChoices`、`PROOF_GROUP_CHOICES`。
  - 新增 **`stageInfo(群记号)`**：认得记号 → 建得出群 → `|G| ≤ 144`，并真算 `|G|` 分解与**每个素因子的 n_p**。
    面板与模板共用它 → 面板上写的 `n₃ = 4` 与模板里写进证明的那个 4 同源。
  - 新增 **`templateReady(模板, 群, p)`**：拦"结构性跑不了"的组合（含 Sylow III + n_p = 1）。
  - `sylowStage(info, p)` 重写：**不再收 genTexts**；具体 P 一律取 Ω 第 1 号点（顺序已与 `Syl_p(G,p)` 对齐）。
  - `gensOfSubgroup`（贪心求生成组，最多 3 个；闭不出来就 `null` → 模板明确报错）+ `genText`（逐字回认）。
  - `orbitsUnder`（P ↷ Ω 的完整轨道分解）· `chooseExact`（BigInt，>20 位只留余数）。
  - 文本全部去 A₄ 化：`n₃` → `n_p`、`「四个 3-子群」` → `${n_p} 个 ${p}-子群`。
- `ui/ProofDock.tsx`：**群一个输入框**（三张卡共用）+ 每张卡一组 **p 按钮（上面直接写 n_p）** +
  「开始证明」；换群后每张卡按 n_p 最大重挑 p；不可跑时红字说明 + 按钮禁用。
- `App.tsx`：`proofRun = {tpl, params}`，`proofSteps` 按参数 build；运行头显示「实例：S_4 · p = 3」。
- `App.css`：`.proof-params` / `.proof-prime` / `.proof-start` / `.proof-bad` / `.proof-instance` 一套。

## 顺带修掉的一个展示层毛病（换到 S₄/S₃ 才显眼）
core 的元素 `label` 在置换群上**单循环不带括号**：S₄ 的 3-轮换叫 `234`、对换叫 `12`，
而双对换却写着 `(12)(34)` → 画布上飘着 `⟨234⟩` 这种**读起来像整数**的节点标签。
- 新增 `ops.ts` 的 **`elementNotation(群, 元素)`**：升格成课本循环记号，**但必须过回认**
  （`resolveElementLoose(g, '(234)')` 命中同一元素才升格）。
  探针实测：C₁₂ 里真有标签 `10`/`11` 的元素，而 `(10)` 解析不了 → 自动留在原样。
- 三处消费：`proof.ts` 的生成元、`elementListHint`、`ElementsTable`（行首 + 拖动载荷）。
- 顺带把 `resolveElementLoose` 从 ops.ts 导出（proof.ts 要拿它做回认）。
