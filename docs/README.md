# docs 导航

按「你是谁」选路。**这个仓库的文档分两类**：
一类是**规范**（说明现在是什么样，改代码前该读，都短），
一类是**账本**（记录每一批为什么这么改，很长，按需检索，不必通读）。

> **边界与纪律**：一段话说"**现在**是什么样" → 写进规范文档；说"**某一次**我们怎么改的、
> 踩了什么坑" → 写进 [HISTORY.md](HISTORY.md)，规范文档里只留**一行摘要 + 指过去**。
> 混在一起，规范就会被账本淹掉 —— ROADMAP 与 USABILITY 曾经有 90% 的篇幅是账本
> （240KB / 218KB），2026-10-04 拆成现在这样。

## 第一次看这个仓库

→ 根目录 [README.md](../README.md)：定位 / 快速开始 / 能写什么 / 怎么跑验证。

**先读方向定案**：[ROADMAP.md](ROADMAP.md) 开头「定位：群论计算器，不是可视化工具」——
它决定"什么需求是本项目的正题"；其余文档与它冲突时以它为准。
