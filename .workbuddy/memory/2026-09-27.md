# 2026-09-27 U24 = 群记号的展示形态能照着敲回去

## 用户诉求
"继续"（承接 U23 留下的"同类风险"清单第一项：**上下标**）。

## 找 bug 的方式：拿 U23 提出的那句判据挨个查
判据："凡**用户能敲一个记号、系统也生成同一个记号**的地方，两侧的归一是不是同一个函数"。
三处候选：上下标 · 循环记号 `(123)` · `⟨⟩`。**第一处一查就见血。**

## 病灶：又是"同一件事两张表"
- `tex.ts`：反向表（`₄` → `4`），供**渲染回 TeX**
- `pretty.ts`：正向表（`4` → `₄`），供**展示**
听着是两个方向、井水不犯河水 —— 实则是**同一组字符的两个视图**。
而**求值链上压根没有"下标字符 → `_n`"这一步**。

实测（修前）：

| 输入 | 结果 |
|---|---|
| `S_4` · `A_4` · `C_6` · `Q_8` | ✓ |
| `S₄` · `A₄` · `C₆` · `Q₈` | ✗ 无法识别：S₄ |
| `C₂×C₂` · `Z₆` · `C₁₂` | ✗ 无法识别 |

**影响面**：画布节点标签（`data-label`）写的就是 `S₄`，信息面板、`docs/` 文档里给的也是 ——
**系统给用户看的每一个记号，都是敲不回来的**。而元素级早有回认
（`resolveElementLoose` ⓪ 层拿 `prettySymbol` 比对），群记号级一直漏着。

## 修法三件
1. 两张表收敛到 `pretty.ts`（`SUB_FROM`/`SUP_FROM`），`tex.ts` 改为 import ——
   渲染要 `_{4}`、回认要 `_4`，**各按目标形态组装，但表只有一份**
2. 新增 **`normalizeScript`**（`S₄`→`S_4`，连续下标合并：`C₁₂`→`C_12`），
   接进 `normalizeExpr`（求值链唯一入口，一处接入即全覆盖）
3. 断言 `verify/suites/notation.ts` **+31** · 新走查 `verify/e2e/copy-label.mjs` **15 条**

## 走查：三条真实复制路径（这条契约端到端才证得了）
1. 抄**画布 `data-label`** → 不动点判据：抄回去建出的标签集合与原集合**相同**
2. 抄**信息面板**里的记号
3. **框选复制的可见文本** —— 拿到的其实是 `S4`（KaTeX 把下标排成了 CSS）

第 3 条是这一轮最有价值的发现：**用户实际复制到的东西，和我们以为的不一样**。
它现在能用，靠的是 core 记号解析器自己的宽容（实测 core 认 `S4`）—— **是运气不是设计**。

## 留下的
- 同类风险还剩两处：**循环记号**（`(123)`）· **`⟨⟩`** —— 判据还是那一句

# 2026-09-27（续）方向变更：文本形态从 Unicode 改成 **简化 LaTeX（全 ASCII）**

## 用户原话
"你给我把键盘上打不出来的字符都处理了，不要显示出来，也不支持输入这些。"

## 三个决定（用户已选）
1. **显示**：KaTeX 渲染，**文本流全 ASCII**
2. **输入**：直接报错，提示改用 ASCII 写法（严格，不做静默归一）
3. **范围**：**全部**，含界面文案里的标点（`—` `…`）

## 这是一次**方向反转**
U23（φ）与 U24（下标）两轮做的都是"**让 Unicode 形态能敲回去**"；
现在改成"**根本不要 Unicode**"。回头看不亏：那两轮的根因分析（"展示与回认必须同源"）
恰好指向了正解 —— 转换链少一跳，那一整类坑就不存在了。

## 链路对比
```
旧：core 的 TeX → prettySymbol → Unicode(S₄) → toTex 反推 → KaTeX     [两跳，有损]
新：core 的 TeX → prettySymbol → 简化 LaTeX(S_4) → KaTeX            [一跳]
                  └→ 文本（复制/输入）也是同一个形态
```

## 已做（这一轮）
- **`prettySymbol` 重写**：只做"省单字符下标的花括号"（`S_{4}` → `S_4`），
  其余**原样保留**（`\varphi` / `\times` / `\mathrm{id}` / `\mathbb{Z}` / `\operatorname{Aut}`）
- **踩到并修掉一个真坑**：原实现 `raw.replace(/\s+/g, '')` **把所有空格删光**
  —— 从前目标是 Unicode 所以无所谓，现在保留 LaTeX 命令后就是错的：
  `C_2\times C_2` → `C_2\timesC_2` → KaTeX 当成未知命令（实测粘连）。
  **LaTeX 里空格是命令的分隔符，删不得。**
- 真浏览器验证：`data-label` 全 ASCII（`S_4` / `ker(f)` / `\operatorname{Aut}(S_4)` / `C_{12}`）·
  KaTeX **零报错** · 视觉零退化（截图 `docs/assets/ascii-preview.png`）

## 剩余四批（未做）
| 批次 | 内容 | 规模 |
|---|---|---|
| A 硬编码展示文案 | `insights/build/ops/proof/relations/evalDef` 里的 `→ · ⊆ ≅ ⊴ ↦ ⟨⟩ ↠ ↪ ↷ ≡ ∣ ∤ ⇔ ↦ pᵏ` | 源码约 50–80 处 |

| D 回归期望值 | `₄` 227 次 · `φ` 168 次 · `→` 265 次 … 的批量替换 | ~800 处 |

**当前状态**：展示层已改，断言必然大面积红（未提交）。等形态确认后一起铺开。

## 这一轮踩的四个坑（全是真的，值得进 verify/README）
1. **TS 字符串里 LaTeX 命令必须写双反斜杠**：`'\to'` ✓ / `'\to'`（单）会被吃成**制表符**
   —— `\t` `\n` `\r` `\b` `\v` `\f` 开头的命令全中招（479 处）。
2. **全局替换会碰"逻辑值"**：`π` `↪` `≅` `Ω` 既是**边标签**（展示）又是**判据 key**
   （`VERTICAL_LABELS`）→ 必须**成对改**，否则布局逻辑静默失效。
3. **id / 参数名不能用 LaTeX**：`NAME_RE` 不许反斜杠 → 名字场合要用纯字母（`phi` / `Omega`）。
4. **批量替换脚本的排除表要用完整相对路径**：我写 `{'gal/pretty.ts'}` 而实际 key 是
   `src/gal/pretty.ts` → **两张映射表被误改**（`GREEK` 表的值全变成 `\alpha `），
   最后靠 `git show HEAD:` 取回基底重建才修好。
   **教训：替换脚本先 dry run 并核对文件清单，别只看字符统计。**
5. 附带：`′`（U+2032）被换成 ASCII `'`，**把字符串字面量提前闭合**（`H′）` → `H'）`）；
   JSX 文本里的 `>` 会触发 TS1382（要 `{'>'}` 或改中文）。

# 2026-09-27（续 3）U25 = 文本形态改成**简化 LaTeX（全 ASCII）**

## 用户诉求（新指令，方向反转）
> 你给我把键盘上打不出来的字符都处理了，不要显示出来，也不支持输入这些。

接着又问了一句："我记得 GroupViz 项目也处理过这一类输入输出问题……你可以参考一下。"
**参考确实有用**：`GroupViz/src/core/algebra/notation/canonical.ts` 里已经做过**同一个决策**
（拒绝 Unicode 上下标），而且理由比我原来的写法更硬 —— 它的注释写着：
"必须保留上下标语义：`C_2²` 要折成 `C_2^2`（而不是 `C_22`），否则提示会建议用户改写成
`C_{22}` —— 那正是原来静默给错群的根源。" 于是 `foldToAscii`（我给"可照抄的改法"用的）
就是照着它的 `foldUnicodeScript` 写的。

## 这一轮的性质：把 U23/U24 的方向掉了个头
U23（φ）与 U24（下标）都在做"让系统生成的 Unicode 记号能敲回去"；现在改成"根本不要 Unicode"。
**回头看那两轮不亏** —— 它们的根因分析（"展示与回认必须同源"）恰好指向正解：
转换链少一跳，那一整类坑就不存在了。

```
旧：core 的 TeX -> prettySymbol -> Unicode(S₄) -> toTex 反推 -> KaTeX   [两跳，有损]
新：core 的 TeX -> prettySymbol -> 简化 LaTeX(S_4) -> KaTeX           [一跳]
                 └-> 文本（复制 / 输入）也是同一个形态
```

## 形态（已与用户确认）
`S_4` · `C_{12}` · `C_2^2` · `\varphi` · `\times` · `\operatorname{Aut}(S_4)`。
规则：**只省单字符下标的花括号，其余原样**。

## 交付
| 面 | 做了什么 |
|---|---|
| `pretty.ts` | `prettySymbol` 重写（只省花括号）· `scanNotAscii`（按码位分类给理由）· `foldToAscii`（整行折成 ASCII 当建议）· `asciiClean`（边界上清外部文案的 `·` `—` `…`） |
| 输入侧 | `UNICODE_ALIASES` 清空 · 符号中缀（`∩ ∪ ∖ · ⊆`）与 `⟨⟩` 别名删掉 · 三个入口都拦（`evalExpr` / `checkName` / `build.ts`） |
| 渲染层（最费工） | `toTex` **幂等** + **中文连空格包 `\text{}`** · 边标签 `<text>` 改成 KaTeX `foreignObject` · 证明面板标题/简述/正文/实例行 · 关系附注 · 体检行 · 悬浮球标签 |
| 断言分工 | **`data-*` 存原始形态**（`data-label` / `data-text` / `data-instance` / `data-detail` / `data-order`），DOM 文本是渲染结果 —— 走查读前者 |
| 回归 | 新 `verify/e2e/no-unicode-leak.mjs` **43 条**：把用户那句话变成可执行判据 |

## 这一轮踩的坑（四个"字符边界"类，全是真踩）
1. **命令与后随字母粘连**：`\timesC_2` 是**不存在的命令**（KaTeX 报错）。判据要扫
   「反斜杠 + 已知命令名 + 紧跟字母」。⚠️ 写扫描器时**不能用带备选分支的正则配 lookahead**
   （会回溯到更短的备选：`subset` 匹配 `\subseteq`、剩下 `eq` 恰好满足"后面还有字母" →
   全是假阳性）；正解是先把「反斜杠 + 字母串」整段抠出来，再看是不是"某命令 + 尾巴"。
2. **单反斜杠被 JS 当成转义**：`'a\to 2'` 只敲一个反斜杠 → `\t` 是**制表符** → 映射建不出来。
   症状是"测试里某个对象凭空不存在"，很难往转义上想。
3. **Unicode 转义（反斜杠 + uXXXX）被改成双反斜杠**：批量替换把 `\u4e00` 也改掉了 →
   `NAME_RE` 的字符类里多了个没意义的字符 → **所有中文名静默被拒**。
   tsc 与正常路径都发现不了，只能靠回归。
4. **分隔点 `·` 被换成 `\cdot`**：语义错位（那是乘法），且在纯文本面原样显示反斜杠字母。
   顺手修了一批（`instanceLabel` / 关系附注 / Ω 点列表 / 提示条）。

还有一条不是"替换"而是"渲染"的坑：**math mode 吃空格** —— `Sylow I · 存在性` 渲染后
`textContent` 是 `SylowI⋅ 存在性`，于是"按标题文本认卡片"的断言全红。正解：认 `data-tpl`。
