# 交换图规范

> 这份文档回答两个问题：**课本级的交换图长什么样**，以及**因此什么对象适合上画布**。
>
> 结论来自 TeX 排版的权威资料——Paul Taylor 的 `diagrams` 包手册（交换图排版的经典文献）、
> `tikz-cd` 官方文档（当代事实标准）、AMS 的 `amscd`——以及数学期刊排版实践
> （MSP 的 *Fine-tuning a TikZ diagram*），并逐条对照 Galculator 的现状。

## 0. 交换图是什么（语法）

交换图只有两种成分：

| 成分 | 数学身份 | 图形身份 |
|---|---|---|
| **对象**（object）| 群、集合、模…… | **顶点** |
| **映射**（morphism）| 同态、同构、包含、投影…… | **边** |

「图交换」= **任取两条同起终点的路径，沿路复合出的映射相同**（方格：`β∘f = g∘α`）。
一个方格是一条方程，一个三角形是一条，一个立方体是六条。定理的"图"因此是**定理内容的等价改写**。

> 交换图不是装饰，是**压缩**：它把写出来要好几行的方程组压成一张图。
> 推论：**图上的每一笔都该在说"某条路径 = 另一条路径"**。
> 与此无关的内容画进去，就是在稀释它的信息密度。

## 1. 六条排版硬规范

### 1.1 对象落在格点上 ★最关键

`tikz-cd` 的核心设计就一句话（官方文档第 2.3 节附近）：

> "The arrows are annotations dropped into that skeleton afterwards, and
> **the positions of the objects are entirely unaffected by how the arrows are written**."

Taylor 说得更细——图被划分成**矩阵的格子**：

> "objects and verticals go in odd-numbered columns, and horizontals and diagonals go in even-numbered columns."

即：**先有格点，后有箭头**。箭头是往格点之间"挂"上去的注解。

**判据**：把图的行列延长成栅格，所有对象都应落在交点上（允许因宽度差异的微调，不允许"漂移"）。

### 1.2 箭头与对象中心对齐 ★

Taylor 开篇列的四条审美标准（原文）：

- Arrows should **stretch to meet** the objects which are intended to be their endpoints.
- Arrows should be **aligned (both horizontally and vertically) with the centres** of the objects.
- Labels on arrows should **not affect the spacing** of the diagram except to avoid overlapping.
- Stretching of arrows should **not affect the centering** of their labels.

第二条是"像不像课本插图"的**第一判据**：**水平箭头必须同高，垂直箭头必须同列。**
一条本该垂直的箭头只要歪几度，整张图立刻显得业余——哪怕其他一切都对。

### 1.3 箭头只允许少数几个方向

课本插图里出现的箭头方向只有三种：**水平、垂直、对角**。
对角箭头是"跨格点"的意思（`tikz-cd` 写作 `\arrow[rd]`），**方向是离散的**，不是任意斜率。

### 1.4 映射标签比对象小一号

MSP（专做数学期刊排版的机构）的实践说明：

> "Typically, map labels along arrows are in a **smaller font size** than the objects the maps go between."

`tikz-cd` 的默认也是 `\scriptstyle`（约 0.7 倍）。

### 1.5 标签摆位只有一条规则：**沿行进方向的左侧**

`tikz-cd` 的 `auto` 规则：右向箭头的左侧 = 上方；下向箭头的左侧 = 左方。
不必为四个方向各记一条规则。加 `'`（单引号）翻到另一侧。

标签太长时可以**压在箭头上**，用背景色把线挖掉一段（`description` 样式）——
这比让标签去挤动布局好。

### 1.6 箭头**形状**编码映射类型

| 形状 | 含义 | `tikz-cd` |
|---|---|---|
| 双箭头 | 满射 | `two heads` |
| 钩子 | 单射 | `hook` |
| 虚线 | 存在唯一 | `dashed` |
| `≅` / `≃` 标在箭头上 | 同构 | `"\simeq"` |

课本里 `π : G ↠ G/K`、`i : im φ ↪ H`、`G/K ≅ im φ` 三种箭头**一眼可分**，
因为它们分别承担定理的三个断言（满、单、双）。

## 2. 现状诊断

### 2.1 布局：列没有对齐（根因）

`apps/web/src/ui/CanvasView.tsx` 的布局分三步：

1. `computeLatticeLayout`（core）给出初始坐标
2. **按层归拢**：同层节点 y 取平均 → 水平方向对齐 ✓
3. **水平防重叠**：从左往右推 `pos[cur].x = minX` → **x 由"左边有几个节点、各自多宽"决定**

于是：**y 是对齐的，x 是推出来的。**
`G` 与 `G/ker φ` 落在不同列 → `π` 那条"垂直"箭头其实是斜的。
**这就是"能用但离课本级差得远"的直接原因。**

> **✅ 已修复（2026-09-17）**：改成**硬约束网格**——行 = 派生层（同层 y 严格相等），
> 列 = **竖直约束**的连通分量（只有 `π` / `π₁` / `π₂` / `↪` 这类结构伴生边要求同列；
> 用户造的映射是水平的、`≅` 是对角的，都不参与），列宽 = 该列最宽节点。
> 实测：第一同构定理自动排成课本的形状（`C₆ ──φ──▶ C₃` 水平、`π` 垂直、`≅` 对角）。
>
> **踩坑**：第一版按几何猜（"`dy ≥ dx` 的边要求同列"），结果 `≅` 这条对角边把
> `C₆`、`C₃`、`C₆/ker φ` 传染成一列，`C₆` 与 `C₃` 直接叠在一起。
> **判据必须按边的语义来，不能按几何猜。**

### 2.2 节点宽度参与布局（次因）

`measure()` 让节点宽度 = KaTeX 实测标签宽度 + padding。
`G`（窄）与 `G/ker φ`（宽）宽度不同 → 推挤时列宽参差 → 列与列之间没有稳定的栅格。

### 2.3 边没有方向约束

边连接任意两个节点中心，斜率任意。课本里只有水平 / 垂直 / 对角三种。

### 2.4 画布混装了"非交换图内容"

`Sub(G)`、`pSub`、元素集这类**列表型产物**也在画布上，靠**来源线**（虚线、可关、
语义是"谁由谁算出"）连起来。来源线不是数学关系，于是画布看起来像**依赖图**。

## 3. 什么对象适合上画布

判据直接来自 §0 的语法：**顶点必须是"对象"，边必须是"映射"**。

| 产物 | 是对象吗 | 上画布？ | 去处 |
|---|---|---|---|
| 群（`S₄` / `G/N` / `ker φ` / `im φ`） | ✓ | **是**（顶点）| 画布 |
| 集合（`Z(G)` / 共轭类等元素集） | ✓（集合之间也可以有映射）| **是**（顶点）| 画布 |
| 映射 / 同构 / 包含 / 投影 | ✓（作为边）| **是**（边）| 画布 |
| **子群集** `Sub(G)` / `pSub` / `Syl` | ✗ 是"对象的集合"，不是对象 | **否** | 信息面板（列表）|
| **元素 / 数值** | ✗ 是"点"，不是对象 | **否** | 元素表 / 数值区 |
| **作用** `共轭作用(G)` | ✓ 是 `G×Ω→Ω` 的关系——**第三种**，既不是顶点也不是边 | **是** | 作用线（与映射箭头视觉可分，见 §5.4 ③）|
| **Ω**（被作用的集合）| ✓ 集合 | **应当是顶点，但现在还不是对象** | 见 §5.4 ①：Ω 目前只是 `GalAction` 里的一个数字 |
| **来源线**（`A` 由 `B` 算出） | ✗ 计算过程，非数学结构 | 辅助 | 虚线，可关 |

**一句话准则**：

> **能作为某个映射的源或靶的，才配当顶点。**

`Sub(G)` 之所以不配：没有任何映射从它出发或指向它。它是个**列表**，
把它画成节点，等于把一张表格塞进交换图。

> **但列表不是死路。** 见 §5.4 ②：Sylow 定理要求 `Syl_p(G)` 这个列表
> **提升成集合 Ω**（取底集）之后才能被群作用。列表是**待提升的池子**。

**推论**：画布应当分成两层——**交换图区**（群 / 集合 / 映射 / 作用）
与**推演产物区**（子群集 / 元素集），后者的视觉权重必须明显低于前者。
（这一条是产品决策，见 §4 的 C。）

## 4. 改造路线

| 编号 | 内容 | 成本 | 收益 |
|---|---|---|---|
| **A** ✅ | **布局网格化**（2026-09-17 落地）：对象指派到整数格点，同列 x 严格相等、同行 y 严格相等；列宽 = 该列最宽节点 | 高 | ★★★ 直接决定"像不像课本" |
| **B** | **节点宽度与布局解耦**：格元尺寸固定，标签溢出不影响列宽 | 中 | ★★ 配合 A |
| **C** | **画布分层**：交换图内容与推演产物分区 / 分权重 | 中 | ★★★ 图立刻变干净 |
| **D** | **箭头形状编码映射类型**：满射双箭头 / 单射钩子 / 同构虚线 + `≅` | 低 | ★★ 定理的三个断言一眼可分 |
| **E** | **标签摆位用"沿行进方向左侧"** + 长标签挖空线 | 低 | ★ 细节 |

### A 的技术路线（硬约束，不是软约束）

网格布局的研究（*Incremental Grid-like Layout Using Soft and Hard Constraints*）结论明确：
**软约束**（"尽量对齐"）会得到 *nearly-but-not-quite aligned* 的结果——
节点看着差不多对齐、实际差几个像素，比明显不对齐更难看。
所以必须用**硬约束**保证行列严格对齐。

做法：

1. 以 core 的 lattice layout 为**初值**
2. 判断每条边的**主导方向**（水平 / 垂直 / 对角）
3. 施加硬约束：水平边两端统一 y；垂直边两端统一 x
4. 迭代至收敛 → 落到**整数格点**（col, row）
5. 按行高 / 列宽算最终坐标（列宽取该列最宽节点）

## 5. Sylow 定理的图长什么样

> 这是本项目 MVP 的目标，所以它的图形结构**直接决定画布该支持什么**。

### 5.1 它不是交换图，是「作用图」

Sylow 三个定理的证明骨架是**同一个模式**：

```
造一个集合 Ω  →  让群作用在它上面  →  分解成轨道  →  数数
```

| 定理 | Ω（被作用的集合）| 作用 | 结论从哪来 |
|---|---|---|---|
| **Sylow I**（Wielandt）| `p^k` 元子集全体 | G 在子集上的自然作用 | 轨道分解 + 计数 mod p |
| **Sylow II** | `G/P` 的左陪集 | H 的左乘作用 | 不动点集非空 ⟹ 存在共轭 |
| **Sylow III** | `Syl_p(G)` | G 的共轭作用 | **只有一个轨道**（由 Sylow II）→ 轨道-稳定子 |

Clemson 的 Macauley 讲义（群作用教学的通用参考）里有一句点明图示约定的话：

> "**the orbits of φ are the connected components in the action diagram**"
> ——轨道就是作用图的连通分量。

### 5.2 三层结构

以 Sylow III 为代表，图是**三层**，而不是一排并列的对象：

```
        φ
  G ─────────▶ Perm(S)          ← 上层：同态（唯一像交换图的部分）
  │
  │ ↷ 共轭作用
  ▼
  S = Syl_p(G)                  ← 中层：Ω，被作用的集合
  │
  │ 轨道分解
  ▼
  Orb(H) = S（唯一）             ← 下层：轨道（Ω 的子集）
  │
  │ 稳定子
  ▼
  Stab(H) = N_G(H) ↪ G           ← 下层：稳定子（G 的子群）

  |Orb(H)| · |Stab(H)| = |G|  ⟹  n_p · |N_G(H)| = |G|
```

**注意上层的箭头与中层的箭头是两种不同的东西**：
`φ: G → Perm(S)` 是**同态**（贴着交换图语法），而 `G ↷ S` 是**作用**（`G×S → S`）。
课本把它们叠在一张图里，但它们不是同一类关系。

### 5.3 轨道分解是「切块」，不是一串独立节点

作用把 Ω 切成若干块，**块的大小 = 轨道长度**。固定点就是长度 1 的块。

```
Ω ┌──────┬─────────────┬──────────────────┐
  │  1   │      3      │        4         │
  └──────┴─────────────┴──────────────────┘
   Fix      O₂              O₃

|Ω| = |Fix| + Σ|Oᵢ|        p-群作用 ⇒ |Ω| ≡ |Fix| (mod p)
```

视觉上这是**一个集合的「内部分割」**，而不是三个并列的对象。
（对应 INTERACTION §2 已有的「数学浓缩（复合节点）」概念。）

### 5.4 对对象栈的启示

| # | 启示 | 现状 |
|---|---|---|
| ① | **Ω 必须是一等对象** | Ω 藏在 `GalAction.n` / `setLabels` 里，**只是一个数字**，不是能上画布的对象 |
| ② | **需要 `list → set` 提升**：`Syl_p(G)` 是列表（按 §3 不上画布），但必须能"取底集"成集合 Ω，才能被作用 | **缺失**。这条正好接上 §3 的结论：**列表不是死路，是待提升的池子** |
| ③ | **作用不是装饰，是主角** | §3 把 `action` 归为 `decoration`（辅助）——**对 Sylow 来说是错的**：三个定理各是一个作用。但它也不是 `edge`（`G×Ω→Ω` ≠ `G→H`），是**第三种关系** |
| ④ | **轨道分解 = 结构伴生**，且同一作用的所有轨道应**一起出现**（它们是 Ω 的一个分割）| 现在 `轨道(A, x)` 是凭空出现的孤立圆节点，Ω 根本不在图上 |
| ⑤ | **数值该贴在对象旁**：`n_p` 是**轨道的长度**，是那个对象的属性；`n_p · \|N_G(H)\| = \|G\|` 的每个因子都该能从图上读出来 | 数值全在数值区，与对象脱节 |

### 5.5 对操作栈的启示：三定理共用一条流水线

```
造集合 → 作用 → 轨道 / 稳定子 → 数值
```

三个定理只是换了 Ω 与作用方式。这条链应当作为**可复用的配方**存在
（ARCHITECTURE §9 的"配方是元数据"），而不是三份各写一遍的操作序列。

## 6. 交换图与作用图如何平衡

> 这是 §5 之后必然要回答的问题：既然 Sylow 的图是"作用图"，
> 那它跟交换图语法不同，画布到底该按哪个来？

### 6.1 先澄清一个容易搞混的地方

"作用图"这个词指的是**两种不同的东西**：

| | **对象级**（证明用的）| **元素级**（举例用的）|
|---|---|---|
| 顶点 | **对象**：群、集合、子群 | **Ω 的元素**（点）|
| 边 | 映射 `G → H`、包含 `H ↪ G`、作用 `G ↷ Ω` | "被 g 搬运"`pt → pt` |
| 核心断言 | 路径无关（方格交换）| 连通性（**轨道 = 连通分量**）|
| 教材里出现于 | **Sylow 三定理的证明陈述** | **讲解"轨道是什么"时的举例** |

Macauley 那句 "orbits are the connected components in the action diagram"，
说的是**下排**；但 **Sylow 定理本身的那几张图全在上排**——
`G`、`Syl_p(G)`、`Orb(H)`、`N_G(H)`，**每一个顶点都是对象**。

**结论：Sylow 的图与第一同构定理的图处在同一层，用的是同一套语法。**
差别只是多了三种元件：

- 一种新**顶点**：集合 `Ω`（现在还不是对象）
- 一种新**边**：作用 `G ↷ Ω`（现在被归成辅助）
- 一种新**内部结构**：轨道分解（`Ω` 的切块）

### 6.2 平衡方案：一种语法，三层密度

```
第 1 层 · 对象级（默认视图）
   对象 + 关系（映射 / 包含 / 作用）
   → 交换图与作用图在这一层完全统一

第 2 层 · 集合内部（展开一个集合节点时）
   轨道分解的切块：块的大小 = 轨道长度
   → Sylow III 里只有一个块（⇒ n_p = |S|）
   → Sylow I 里要数这个划分（|Ω| ≡ |Fix| mod p）

第 3 层 · 元素级（很少需要）
   "g 怎么搬运点" —— 不进画布，去信息面板的横滚表格
```

**默认停在第 1 层**。需要时才对某个集合节点下钻一层。
这套"渐进展开"不是新机制——它就是 INTERACTION §2 早就写的
「数学浓缩 / 视觉折叠」，只是现在有了明确的**下钻顺序**。

### 6.3 一句话判据

> **画布画「对象之间的关系」；面板画「元素之间的关系」。**

| 图 | 第 1 层 | 第 2 层 | 需要第 3 层吗 |
|---|---|---|---|
| 第一同构定理 | `G → H`、`G/ker φ`、`im φ` + 三条边 | — | 不需要 |
| Sylow III | `G ↷ S = Syl_p(G)` | 展开 `S`：**一个**轨道块 | 不需要 |
| Sylow I | `G ↷ X`（`p^k` 元子集）| 展开 `X`：数块大小 | 不需要 |
| 讲解"轨道是什么" | — | — | **需要**（Cayley 式，通常放面板）|

### 6.4 实现要求（三条）

1. **`Ω` 升格为对象**：从 `GalAction` 的内部字段变成真正的集合对象，能上画布、能被选中；
2. **作用成为一等边**：与映射箭头视觉可分，但同样是图的正式成员；
3. **集合节点可展开**：展开后显示轨道分解的切块（第 2 层）。

这三条做完，`第一同构定理` 与 `Sylow III` 就能画在**同一张画布**上，
而画布只有一种语法。
