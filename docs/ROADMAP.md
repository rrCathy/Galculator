# 开发规划

## 技术栈定案

| 层 | 选型 |
|---|---|
| 前端 | React 19 + TypeScript + Vite |
| 后端 | 扩展 GroupViz GAP（FastAPI + GAP 4.16）|
| 复用 | `@groupviz/core` v2.3.0（npm，纯算法层）|
| 渲染 | `@groupviz/react` v2.3.0（10 个 Scene）+ 自研交换图画布 + KaTeX |

## 阶段划分

### 阶段 0 — 奠基：画布图最小闭环（M0）✅ 已完成

- **已交付**：pnpm monorepo + `apps/web`（Vite + React 19 + TS）；装 `@groupviz/*` v2.3.0；
  `CanvasGraph = derive(objects, ops)`（见 INTERACTION §10）+ `computeLatticeLayout` 分层布局；
  自研 SVG 交换图画布（节点卡 + 两类边）。
- **里程碑达成**：输入 `G = D_4`、`P = G x H`、`Z = Z(G)`，画布长出节点与边并自动分层（见 README 截图）。
- **遗留**：操作是 `evalDef.ts` 里硬编码的 if-else，只有 `Z(G)` 与 `×` 两条 —— **已由 M0.5 收口**。

### 阶段 0.5 — 按架构落地操作层（M0.5）✅ 已完成

- 目标：把操作层从"硬编码"换成 [ARCHITECTURE.md](ARCHITECTURE.md) 定义的**注册表 + 值类型**。
- 已交付：
  - 值类型扩到 **6 种**（`group` / `elements` / `subgroups` / `map` / `action` / `number`）+ 子群归一化（`Subgroup` / `PSubgroupInfo` / `SylowSubgroupInfo` 拉平为 `NormalizedSubgroup`）。
  - **`gal/ops.ts` 注册表**：20 个操作，每条声明 = 机制归类 + 调用名/中缀 + 参数个数 + 产出值类型 + core 落点 +（可选）配方 + 求值函数。覆盖六个机制：原子构造 5 · 作用导出 6 · 枚举+筛 4 · 迭代 1 · 属性 1 · 算术 3。
  - **`evalDef.ts` 五级分发**：对象引用 → 函数式调用 → 顶层中缀 → 记号建群；参数递归求值，**来源线自动从参数链收集**（不再是每个操作手写）。
  - **操作面板**（左栏「可用操作」）：由注册表按机制分组生成，点击插入模板——注册表驱动的第一个 UI 入口。
  - 画布新形状：**作用线**（绿色实线 + ↷）、子群集/元素集统一为圆；节点尺寸按标签实测宽度自适应，同层水平去重叠 + y 对齐。
- 里程碑达成：`P = pSub(G, 2)` 出「子群集」节点；`A = 共轭作用(G)` 出作用节点与作用线。
- 验证：`tsc --noEmit` 0 错误；core 逻辑 24/24 断言通过（`|Orb|×|Stab| = 2×4 = |G| = 8`）；真浏览器控制台零错误。
- **遗留**：`map`（映射）只有值类型与派生分支，无生产者——需「对象编辑器」（生成元填像）才能落地；`orbits` / `stabilizers` 的陪集作用分支、`半直积 ⋊`、识别类均待后续。
- 依据：ARCHITECTURE §2–§5。

### 阶段 1 — Proof Spec 引擎（M1）

- 目标：执行器 + 第一份模板。
- 任务：
  - `ProofSpec` / `ProofStep` / `ComputeCall` / `ShowSpec` 类型定义。
  - 执行器：依赖解析 + 逐步执行 + local/backend 分发。
  - Sylow I（Wielandt）模板。
  - step-through UI（前进 / 后退 / 高亮）。
- 里程碑：Sylow I（Wielandt，13 步）在 A₄ 上跑通，每步高亮对应 Scene。

### 阶段 2 — Sylow 三定理（M2）

- Sylow II（共轭性）、Sylow III（n_p ≡ 1 mod p）。
- 复用轨道 / 共轭计数原语。
- 里程碑：三份模板，任意输入群（≤ 某阶）跑通。

### 阶段 3 — 定理库 + 交互打磨（M3）

- Cayley 定理、第一同构定理、orbit-stabilizer 定理模板。
- 交换图画布打磨（对齐 Desmos 简约感）。
- 里程碑：定理库 5+ 模板。

### 阶段 4 — 发布 + 教育模式（远期）

- web 部署；教育模式（联动 GroupViz GVL）；app（远期）。

## UI 重构线（U0–U6，与 M1 交织）

> 由「在对象旁边完成操作」这一理念驱动，交互规格见 [INTERACTION.md](INTERACTION.md)（v2，含 5 条决策）。
> 这条线优先于 M1 —— 因为 M1 的 Sylow 模板要让用户**逐步操作**，没有顺手的入口就演示不起来。

| 阶段 | 内容 | 可见成果 | 依赖 |
|---|---|---|---|
| **U0** | 注册表补 `params` + `opsFor(selection)`；补集合运算（∩ ∪ \ ·）；映射引擎侧 op；元素参数走 `resolveElement`；`Z(G)` 等升级为真群对象（`buildSubgroupGroup`）| `A ∩ B` · `⟨S⟩` 可用；`Z(A₄)` 出方节点、可继续 `Z(Z(G))` | — |
| **U1** | 输入框拆「名字 / 表达式」两栏 + 自动命名（避开注册表调用名）| 不用自己想名字 | U0 |
| **U2** | 画布交互状态机 + 径向菜单（看/算/造三类）+ 左栏详情态（竖卡）| **在对象旁边就能操作** | U0、U1 |
| **U3** | 映射构建器（生成元填像）+ 结构伴生箭头（π / H↪G / 积投影）| **交换图上第一条实线箭头**；`ker`/`im` 可用 | U2 |
| **U4** | 顶部工具条 + 群目录手风琴 + 操作表 modal | 点着就能做，不用记语法 | U2 |
| **U5** | **集合构造器**：分面表格（列 = 类型×属性表）+ 属性谓词 + 字谓词（`parseWord`）+ 固化/再编辑 | `{x ∈ A₄ : x²=e}` 点着造出来，并顺手写出等价文本；同一机制可造 `{x : 阶=2}`、`{H : 正规}` | U4 |
| **U6** | 拖动 + 手动布局（钉住语义 + 持久化）| 可自行摆形状 | U2 |
| **U7** | 宏（先纯重放）| 常用组合一键复用 | U3、**建议等 M1 之后**（与 Proof Spec step 序列同构）|

## 依赖与风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| `@groupviz/*` 版本演进 | 对接层跟进成本 | 锁版本号；协议（GroupDescriptor v1）已固化 |
| `sylow` 视图未入包 | Sylow 可视化需自绘 | 用 Set / Coset 组合表达，或自研 |
| 后端端点需新写 | 后端工作量 | local 原语优先；M0/M1 前端够用，后端推迟 |
| 巨大集合（X = 全体 pᵏ 子集）| 无法枚举 | 粒度 C：只算计数不枚举 |
