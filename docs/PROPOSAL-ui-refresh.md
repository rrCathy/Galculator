## 0. 现状与约束

**现状一句话**：白底 + 玻璃卡 + 蓝紫点缀的系统字体界面；工作台 v2 刚验收（用户「对味了」），
但全应用仍是「一屏浮白卡」——画布、侧栏、工作台、工具条同为白卡 + 软影，**分区靠位置、不靠气质**。

走查时实测到的三处具体问题（与选哪版无关，都应顺手治）：

| # | 问题 | 证据 |
|---|---|---|
| 1 | **`＋` 面板没有「点外 / Esc 关闭」**；按 Esc 反而把焦点清掉、面板不关 | 真机复现（[截图](assets/ui-refresh-before-esc-quirk.png)）：预设焦点 D₄ 后按 Esc → 显示条回「还没有对象」，`＋` 浮层仍在 |
| 2 | 底部工具条 8 个全文字按钮**无分组**（连线 / 视图 / 清空画布混排） | 现状截图右下 |
| 3 | 工作台默认 68vh 盖住画布节点，台内换焦点只能靠槽位 / 台面 | 已知设计取舍（INTERACTION §4.9），三版不动它的行为 |

**硬约束**（三版全部遵守）：

- **不动数学排版**（KaTeX 原样）· **不动 ops 语义** · **文案纪律照旧**（全中文，无英文泄漏）。
- **e2e 36 套按 DOM 类名找元素**（`.gnode-hit` / `.bench-key[data-op]` / `.cat-*` …）：
  **只换皮（L1/L2）不破走查；动结构（L3）要同步改对应 suite**——见 §6。

## 1. 三方向速览

| | **A · 静水** | **B · 仪器台** | **C · 演算纸** |
|---|---|---|---|
| 一句话 | 同语言精修：装置退后，内容发光 | 把应用做成一台北欧仪器 | 一页排版精良的数学手稿 |
| 底色 | 冷白 `#FBFCFC` | 石墨 `#14161A` | 冷纸 `#FAFAF6` + 方格 |
| 记忆点（签名） | **身份色带**：一类数学身份一条颜色线（节点→边→侧栏→键盘） | **键帽 + 状态灯**：键有真实深度，每处活跃状态一枚发光小灯 | **双色墨**：黑墨写内容，红笔只写「等你动作」 |
| 性格 | 安静、专业、克制 | 机器感、久看不累、夜里舒服 | 学院气、慢读、印刷味 |
| 风险档 | 低 | 中高 | 中 |
| 最大代价 | 不惊艳（它是"把现在做深"） | App.css 全面重写 + 逐屏对比度校对 | 字体策略（思源宋体）+ 小字号宋体渲染实测 |

## 2. 方向 A · 静水（风险：低）

> **主张**：保留现在这套玻璃语言，但把「装置」和「内容」分成两级——侧栏、工作台、
> 工具条全部退回素灰；颜色只留给画布上的数学内容。教学用户不需要重新学界面。

**Token 系统**（样张 Token 卡同款）：

- 色板：纸面 `#FBFCFC` · 面板 `#FFFFFF` · 装置灰 `#F3F6F9` · 描边 `#E3E6E9` · 墨 `#1F2328` · 静水蓝 `#1E63C8`
- 身份色（5 枚）：群 `#1E63C8` · 集合 `#0F7B8A` · 映射 `#6E56CF` · 作用 `#2E7D52` · 关系 `#A66B1E`
- 字体：UI 无衬线（现字体栈不变）；数学/对象名统一衬线斜体（KaTeX 之外的地方也守住）；数字开启等宽数位
- 圆角三级 9 / 12 / 18；阴影三级（装置 1 级、浮层 2 级、工作台 3 级）

**用户看得见的变化**：

1. 侧栏、工作台、工具条统一「降噪」：阴影更轻、边框更细，画布内容成为屏幕上唯一着色物
2. **每一类对象有身份色**：节点顶沿 3px 色带、连线、侧栏头部、键盘键左缘走同一条颜色线
3. 工具条 8 键收成 3 组胶囊：**连线 / 视图 / 清理**（「清空画布」从「连线」旁边挪开）
4. 工作台玻璃再透一档：背后的画布节点更可见（原位不动，纯 CSS）
5. 键悬停 500ms 出中文全名 + 一句说明（现在即刻弹，容易误触）

**代价**：以 L1 + L2 为主；L3 只动工具条分组（改 1 套走查）。

## 3. 方向 B · 仪器台（风险：中高）

> **主张**：这个应用是工具，不是文档。那就把它做成一台北欧仪器——石墨机身、
> 丝印标签、发光的答案。画布上的数学对象是全屏唯一发光的东西。

**Token 系统**：

- 色板：石墨 `#14161A` · 面板 `#1E2126` · 键面 `#262A30` · **丝印奶油 `#E7E3D8`**（不用纯白，眼睛不刺）· 信号蓝 `#5CA8FF` · 警示 `#FF6B6B`
- 身份色（5 枚发光信号）：群 `#5CA8FF` · 集合 `#E8B84B` · 映射 `#B08CFF` · 作用 `#58C98B` · 关系 `#FF8A5C`
- 字体：UI 无衬线 + **丝印处理**（小号、大字距、奶油色）；数字等宽；数学 KaTeX 不变

**用户看得见的变化**：

1. 全应用变深色仪器，**画布对象是唯一亮的东西**——视线自然落在数学上
2. 键盘有**真实键帽深度**（上高光 / 下厚边）+ 按压位移；待选的键发光
3. **每处活跃状态一枚小灯**：焦点节点、待选键、开着的侧栏——状态不再靠文字说
4. 侧栏从「浮卡」变「入榫机箱」：硬边 + 内高光，不再是软影漂浮
5. 面板标题走丝印（小号大字距），中文不变，只是排版变「机器面板」

**代价**：App.css 颜色/阴影/边框体系全面重写；**每一屏都要做对比度校对**（深色底上的
数学真值与提示文字是重灾区）；e2e 选择器不破（只换皮），但可视化走查（截图面）36 套全量复跑。

## 4. 方向 C · 演算纸（风险：中）

> **主张**：数学本来就写在纸上。让整个应用像一页排版精良的手稿：冷纸白、方格、
> 黑墨写内容、**红笔只写状态**——就像真的演算稿上，黑笔记推导、红笔圈疑问。

**Token 系统**：

- 色板：纸面 `#FAFAF6` · 纸卡 `#FFFFFE` · 方格 `#E9E9E2` · 墨 `#202226` · 笔蓝 `#274C9E` · **批注红 `#BE3A2B`**
- 身份色（5 枚墨色）：群 `#274C9E` · 集合 `#0E6F78` · 映射 `#5B4B9E` · 作用 `#2F6B45` · 关系 `#8A5A18`
- 字体：**标题 / 对象名走衬线**（生产建议思源宋体，样张用系统衬线近似）；正文保持无衬线（兼容小字号）；数学 KaTeX 不变

**用户看得见的变化**：

1. 画布变**方格纸**（120 / 24 双频网格），节点变印刷框、子群集合变虚线说明圈
2. **红笔纪律**：红色只出现在「等你动作」的地方（待选键、提示、错误）；其余一律黑墨
3. 侧栏变**页边注**：细规则线 + 衬线小标，像教科书页边
4. 工具条变页脚：去胶囊化，· 分隔的素文
5. 对象名/读数衬线化，数字带等宽数位——阅读感向「印刷」靠

**代价**：换肤 + 字体策略（引入一份衬线 CJK 字体，需实测小字号渲染，必要时局部回退）；
满屏方格若嫌吵，可降级为一档弱网格（样张已是双频，有强弱层次）。

## 5. 建议怎么选

- **首选：B 为主，A 的系统件当地基。** 定位上这是"计算器/仪器"，B 的直接兑现度最高，
  顺带把「白上白」层级问题一起治了；A 的三个系统件（身份色带、字阶、影分级）在 B 里原样成立。
- **想小步快跑：先做 A + §0 的三处小修正**，一波验收看手感，再决定要不要继续往 B 走。
- **C 的定位**：气质最独特，但"慢读"性格与高频操作场景需要磨合——**建议留作后话**
  （例如将来做「证明视图」的皮肤：读证明时切手稿，算的时候用 A/B）。
- 三版都**不回答**的一件事：工作台盖画布的行为（68vh / 槽位换焦）——那是交互题，
  本次只换皮；要动它另开提案。

## 6. 施工分级（怎么落地，破不破走查）

| 级 | 动什么 | 破走查？ | 例子 |
|---|---|---|---|
| **L1 变量层** | `:root` 色板 / 字体 / 圆角 / 影重定 | 否 | 全应用换色 |
| **L2 皮肤层** | 各组件 CSS 重写，DOM 不动 | 否 | 键帽深度、丝印标题、身份色带、页边注 |
| **L3 结构层** | 少量 DOM 调整 | **是**（改对应 suite） | 工具条分组（改 `layout-spec` 等）、`＋` 面板 Esc 关闭（改 `workbench.mjs`） |

- 三版的施工顺序都建议：**L1 → L2 → L3**，每级一验收（截图对比 + 走查复跑）。
- B 方向需额外加一件：**深色对比度巡检**（把"看不清的字"变成可回归的断言，
  类似 `no-unicode-leak` 的做法，新开一个 suite 或并入其一）。
